# 部署到自己的服务器（免 ICP 备案）

> 为什么要走这条：WorkBuddy Sites 的分享链接在**微信内会被平台网关拦截**（提示「当前应用不支持在微信内打开」），这是平台限制，换域名或做备案都绕不过去。
> 本方案把站点搬到**香港服务器 + 自有域名**：ICP 备案制度只约束境内服务器，境外托管无需备案，且代码**不需要任何修改**。

---

## 一、要买什么

### 1）一台香港服务器

- 腾讯云 / 阿里云，搜「**轻量应用服务器**」
- 地域必须选 **中国香港**（选内地地域就必须备案）
- 配置：**2 核 2G**、镜像选 **Ubuntu 22.04**
- 费用量级：约 24–60 元/月（年付更便宜）

### 2）一个域名

- 在同一个云厂商买（腾讯云 DNSPod / 阿里云万网均可）
- 后缀随意：`.com` 首年几十元，`.xyz` / `.top` 首年十几元
- 买完必须做一条解析：
  - 记录类型 **A**
  - 主机记录 **@**
  - 记录值 **服务器的公网 IP**

> 域名**不需要备案**——备案只针对解析到境内服务器的域名。

---

## 二、部署（三条命令）

在云控制台点「**登录 / 远程连接**」（网页终端，不用装任何软件），然后依次粘贴：

```bash
apt update && apt install -y git
```

```bash
git clone https://github.com/wangjing1011/wenxing-h5.git /opt/wenxing
```

```bash
cd /opt/wenxing && bash deploy/setup.sh 你的域名 你的AI_KEY
```

第三条把 `你的域名` 换成实际域名（如 `wx.example.com`），`你的AI_KEY` 换成大模型密钥。

脚本会自动完成：装 Node 20 → 装 Caddy 并申请 HTTPS 证书 → 写配置 → 注册开机自启 → 启动自检。约 1–3 分钟。

---

## 三、验证

1. 浏览器打开 `https://你的域名`，能正常看到首页
2. **微信里打开同一个链接**，确认不再出现「请在浏览器中打开」
3. 抽一组牌，点「AI 解读」，确认能出内容

---

## 四、日常维护

| 要做的事 | 命令 |
|---|---|
| 看实时日志 | `journalctl -u wenxing -f` |
| 重启应用 | `systemctl restart wenxing` |
| 更新代码 | `cd /opt/wenxing && git pull && systemctl restart wenxing` |
| 更换 AI Key | `cd /opt/wenxing && bash deploy/setup.sh 你的域名 新Key` |
| 看证书是否签发成功 | `journalctl -u caddy -n 50 --no-pager` |

---

## 五、排障

**打不开网页 / 证书申请失败**

1. 域名解析没生效：`ping 你的域名` 看是否返回服务器 IP
2. 云控制台「防火墙 / 安全组」没放行：需要开 **80** 和 **443** 两个端口（80 用于证书验证，证书签好后可只用 443）
3. 解析生效和证书签发通常需要等 1–5 分钟

**微信里还是打不开**

先确认在手机浏览器里能打开。如果浏览器能开、微信不能，把域名发我，我再排查是不是内容层面的风控。

---

## 六、安全说明

- 密钥只写在服务器 `/opt/wenxing/ai-proxy/.env`，权限 600，**不会进 Git 仓库**
- 应用只监听 `127.0.0.1:8787`，外部只能通过 Caddy 的 HTTPS 访问，绕过不了证书
- 建议服务器开启云厂商的「快照 / 备份」，改坏了可以回滚
